# Nemotron Voice Agent SQA Architecture

This directory retains one canonical, static view of the Nemotron Voice Agent
software quality assurance (SQA) system:

- `nemotron-voice-agent-sqa-system.pptx`: editable one-slide presentation.
- `nemotron-voice-agent-sqa-system.png`: 3,840 × 2,160 preview.
- `nemotron-voice-agent-sqa-system.svg`: editable vector source.
- `EVIDENCE_AND_VALIDATION.md`: inspected sources, evidence boundaries, and
  validation notes.

The temporary Python generators, drawing toolkit, caches, build reports, and
alternate audience variants are intentionally not retained in the repository.
Use the authored SQA sources under `tests/` as the behavior source of truth.
When the architecture changes materially, update the three canonical outputs
together and revise the evidence note.
